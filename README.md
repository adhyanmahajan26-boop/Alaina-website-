# Alaina Shockers

Marketing website for **Alaina Shockers** — rare struts, dampers, and heavy-duty
cabin dampers engineered for India's commercial trucks (Eicher, Leyland, Tata) and
passenger vehicles.

A static, dependency-free site: no framework and no build step for the browser.
Every inner page is generated by `scripts/build_seo.py` from the catalogue data in
`index.html`.

## Features

- Graphite and signal-orange design system with light and dark themes
- Interactive 3D cabin damper in the hero (hand-written WebGL, no libraries): drag to
  spin, it reacts to scroll, then comes apart part by part in the "Inside a cabin
  damper" section. Falls back to a product photo when WebGL is unavailable
- Phone-first: bottom dock (catalogue, search, Superlift, WhatsApp), quick-view
  bottom sheet for each part, swipeable range cards, sticky search and filters
- Catalogue with search and filters, a static page per part number, category and
  vehicle landings
- `/alaina-x-superlift/`: the Superlift gas spring catalogue shown as a partner line
- WhatsApp enquiry on every card and page; contact form that opens WhatsApp
- Self-hosted variable fonts (Archivo, Inter, JetBrains Mono)

## Tech

- Plain **HTML + CSS + JavaScript**
- `style.css` design system, `site.js` shared behaviour, `hero3d.js` the WebGL damper
- Python (Pillow, numpy) only for generating pages, WebP images and favicons

## Run locally

```bash
python3 -m http.server 5174
# then open http://localhost:5174
```

## Regenerate pages

```bash
python3 scripts/build_seo.py   # every inner page, sitemaps, robots, .htaccess, SEO.md
python3 scripts/check_seo.py   # titles, meta, one H1, JSON-LD, links, sitemap
```

Header, footer, icons and the logo mark live in `scripts/site_chrome.py`. The homepage
carries a literal copy, so change both together. Bump `ASSET_VERSION` there (and the
`?v=` numbers in `index.html`) when `style.css`, `site.js` or `hero3d.js` change.

The Superlift catalogue is copied from the Mahajan Motors India site repo, by hand,
when that catalogue changes:

```bash
python3 scripts/import_superlift.py /path/to/mmi-website/artifacts/mahajan-motors
python3 scripts/build_seo.py
```

## Structure

```
.
├── index.html            # homepage, catalogue data (PRODUCTS) and catalogue script
├── style.css             # design system for every page
├── site.js               # theme, menu, header, reveal, dock (every page)
├── hero3d.js             # WebGL damper (homepage)
├── fonts/                # self-hosted variable fonts
├── images/               # product photos, images/web (WebP), images/superlift
├── products/ …           # generated pages (do not edit by hand)
├── alaina-x-superlift/   # generated partner page
├── scripts/              # build_seo.py, check_seo.py, site_chrome.py, import_superlift.py …
└── SEO.md                # generated SEO notes
```
