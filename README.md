# Alaina Shockers

Marketing website for **Alaina Shockers** — rare struts, dampers, and heavy-duty
cabin dampers engineered for India's commercial trucks (Eicher, Leyland, Tata) and
passenger vehicles.

A static, dependency-free site: no framework and no build step for the browser.
Every inner page is generated by `scripts/build_seo.py` from the catalogue data in
`index.html`.

## Features

- Graphite and signal-orange design system with light and dark themes
- Rendered films instead of a spinning part. In the hero a car drives in and stops, its
  body lifts apart and turns to glass, and the camera goes in to the front strut. Under
  "Inside a cabin damper" scrolling brings a truck in, lifts its cabin apart and goes in
  to the cabin damper where it sits on the chassis, then takes the damper apart with a
  close-up of every part. The shocker section does the same with a light truck and its
  axle shocker, and the strut section with the car's rear strut. Every frame is pre-rendered (Blender Cycles) and played on a 2D canvas,
  so it looks the same on every phone. With reduced motion or no JavaScript each film
  is a still image and the damper tour is a plain list of parts
- The catalogue is its own full-screen view. "Open catalogue", the dock and any
  `#catalogue` or `#find` link open it over the page; Back, Escape or the browser's
  back button return to where the reader was
- Every catalogue photo cut out and set at the same angle, size and light
  (`images/cards/`); the original PNGs stay the `<img src>` for search engines
- Phone-first: bottom dock (find a part, WhatsApp), quick-view bottom sheet for each
  part, one swipeable row per make in the catalogue, sticky search and filters
- Catalogue with search and filters, a static page per part number, category and
  vehicle landings
- `/alaina-x-superlift/`: the Superlift gas spring catalogue shown as a partner line
- WhatsApp enquiry on every card and page; contact form that opens WhatsApp
- Self-hosted variable fonts (Archivo, Inter, JetBrains Mono)

## Tech

- Plain **HTML + CSS + JavaScript**
- `style.css` design system, `site.js` shared behaviour, `stage.js` the film players
- Python (Pillow, numpy) only for generating pages, WebP images and favicons; Blender
  (`pip install bpy`) only for re-rendering the films

## Run locally

```bash
python3 -m http.server 5174
# then open http://localhost:5174
```

## Regenerate pages

```bash
python3 scripts/build_seo.py   # every inner page, sitemaps, robots, .htaccess, SEO.md
python3 scripts/check_seo.py   # titles, meta, one H1, JSON-LD, links, sitemap
```

Header, footer, icons and the logo mark live in `scripts/site_chrome.py`. The homepage
carries a literal copy, so change both together. Bump `ASSET_VERSION` there (and the
`?v=` numbers in `index.html`) when `style.css`, `site.js` or `stage.js` change.

The Superlift catalogue is copied from the Mahajan Motors India site repo, by hand,
when that catalogue changes:

```bash
python3 scripts/import_superlift.py /path/to/mmi-website/artifacts/mahajan-motors
python3 scripts/build_seo.py
```

## Product photos and the rendered films

```bash
python3 scripts/build_cards.py            # images/cards/*.webp from images/*.png (after adding a photo)

# only when a model or a camera path changes (about two hours for everything on 4 CPU cores)
pip install bpy
python3 scripts/render/films.py car   /tmp/frames --res 800 --samples 40 --threshold 0.035   # hero: car and front strut (c000–c077)
python3 scripts/render/films.py cabin /tmp/frames --res 720 --samples 24 --threshold 0.045   # truck and cabin damper (b000–b058)
python3 scripts/render/films.py axle  /tmp/frames --res 720 --samples 24 --threshold 0.045   # light truck and axle shocker (x000–x058)
python3 scripts/render/films.py rear  /tmp/frames --res 720 --samples 24 --threshold 0.045   # car from behind and rear strut (q000–q077)
python3 scripts/render/encode_films.py /tmp/frames seq    # seq/film and the stills car, axle, rear

python3 scripts/render/damper.py /tmp/frames scripts/render/sequence.json --res 1080 --samples 96   # the damper tour
python3 scripts/render/encode.py /tmp/frames seq          # seq/720, seq/1080 and the still poster
python3 scripts/render/partner.py /tmp/partner.png        # the Alaina × Superlift image
python3 scripts/render/encode.py --partner /tmp/partner.png images
```

The vehicles are built in code, with no downloaded models: `vkit.py` holds the shared
modelling, studio and animation helpers, `sedan.py` the car, `truck.py` the heavy tractor
and the light truck, and `films.py` the four films (`--only 40-50` re-renders part of one).
The dampers, shockers and struts on the vehicles are the same models as the product
renders (`damper.py`, `lines.py`). A film's frame count is on its canvas in `index.html`
(`data-c`, `data-b`, `data-n`); change it there if a film gets longer or shorter.

`sequence.json` lists the damper frames: `s000`–`s084` the scroll tour and `r00`–`r11`
the unit cycling on the rig (`stage.js` holds the matching counts).

## Structure

```
.
├── index.html            # homepage, catalogue data (PRODUCTS) and catalogue script
├── style.css             # design system for every page
├── site.js               # theme, menu, header, reveal, dock (every page)
├── stage.js              # players for the rendered films (homepage)
├── seq/                  # rendered frames (WebP): seq/film the vehicle films, seq/720 and seq/1080 the product close-ups
├── fonts/                # self-hosted variable fonts
├── images/               # product photos, images/cards (matched cut-outs), images/superlift
├── products/ …           # generated pages (do not edit by hand)
├── alaina-x-superlift/   # generated partner page
├── scripts/              # build_seo.py, check_seo.py, site_chrome.py, build_cards.py, render/ …
└── SEO.md                # generated SEO notes
```
