## Gaps

**None.** Every real route has a prerendered file that Apache/LiteSpeed will serve after the homepage SPA fallback is removed. No exception rewrite is required.

## Notes

- `sitemap.xml` is a sitemap index. Its `<loc>` values are `sitemap-pages.xml` and `sitemap-products.xml` (real files), not HTML pages.
- `/dickey-bonnet-struts/` is generated by `build_seo.py` and prerendered, but omitted from the sitemaps while empty (`noindex,follow`). It is still a real route.
- Page files are `index.html` at the URL path (`/cabin-dampers/` → `cabin-dampers/index.html`). Homepage is `index.html` at the site root.
- Live unknown URLs (`/this-does-not-exist`, `/404.html`) currently return **200** with the homepage body because of `RewriteRule ^ index.html`.
